Bantuan
  1. Jalankan build server (folder server/, lihat README.md) lalu cek indikator di pojok kanan atas.
  2. ZIP → APK: upload ZIP, isi nama, package (mis. com.dimz.app), versi & ikon, klik Build APK, lalu download.
  3. HTML → APK: pilih file HTML (boleh beserta CSS/JS/gambar).
  4. ZIP → Website: upload ZIP, cek preview, download ZIP siap hosting.
  5. HTML → Website: tulis kode, lihat live preview, download HTML atau ZIP.
Package name hanya huruf kecil, angka, underscore, minimal dua segmen dipisah titik.
